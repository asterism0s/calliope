## [1.1.0] - 2026-10-07

### Changed
- Table body now uses the interface font, with taller rows
- Stronger active tab shadow in light mode
- Darker dot grid in code blocks in light mode
- Replaced a `:has()` selector with `el-*` classes to improve performance

### Fixed
- Added `-webkit-` prefixes to icon masks so file explorer icons work in older Obsidian versions
